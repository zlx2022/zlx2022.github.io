前言

想拥有一个属于自己的博客，但不想买服务器、不想折腾 Nginx？Hexo + GitHub Pages 是目前最适合新手的免费方案：

  • 本地用 Markdown 写文章
  • Hexo 自动生成静态网页
  • 推送到 GitHub 后免费托管
  • 访问地址：https://你的用户名.github.io

本文记录了我从零搭建到成功部署的完整流程，以及踩过的所有坑和解决办法。

一、整体思路

需要准备：

  • 一台电脑（Windows / Mac 均可）
  • Node.js
  • Git
  • GitHub 账号（免费）

不需要： 买服务器、备案（使用 *.github.io 子域名时）

注意： Gitee Pages 已于 2024 年停服，目前推荐使用 GitHub Pages 或 Cloudflare Pages。

五、写文章

5.3 常用命令

命令 作用
hexo new "标题" 新建文章
hexo s 本地预览
hexo g 生成静态文件
hexo clean 清理缓存
hexo d 部署到远程

六、插入图片

6.1 不能直接在记事本里粘贴图片

Hexo 文章是 .md 文本文件，需要把图片保存为文件，再写引用路径。

6.2 推荐方式：放到 source/images/

关键： 路径必须以 / 开头，写成 /images/xxx.jpg。

6.3 用 VS Code / Cursor 粘贴图片

  1. 安装插件 Paste Image（作者 mushan）
  2. 打开整个博客文件夹
  3. 配置 .vscode/settings.json 后，用命令面板执行 Paste Image

6.4 图片不显示的排查

现象 解决
裂图 / alt text 改成 /images/xxx.jpg
图片在 _posts 目录 移到 source/images/

七、部署到 GitHub Pages（一键推送）

7.1 创建 GitHub 仓库

仓库名必须是：你的用户名.github.io（例如 zlx2022.github.io）

7.2 安装部署插件

7.3 配置 _config.yml

7.4 创建 GitHub Token

  1. GitHub → Settings → Developer settings
  2. Personal access tokens → Tokens (classic) → Generate new token
  3. 勾选 repo 权限，复制 Token（ghp_ 开头）

链接：https://github.com/settings/tokens/new

7.5 一键部署

登录时：Username 填 GitHub 用户名，Password 填 Token。

7.6 开启 GitHub Pages

仓库 → Settings → Pages → Branch 选 gh-pages → Save

访问：https://zlx2022.github.io

八、常见报错与处理

8.1 Cannot find module fs/promises

8.2 Port 4000 has been used

8.3 页面显示 Pug 源码

8.4 图片裂图

错误：![图](image.png)
正确：![图](/images/image.png)

8.5 Authentication failed

Password 必须填 Token，不是 GitHub 登录密码。

8.6 部署后 404

检查 GitHub Pages 是否选了 gh-pages 分支，重新 npm run pub。

8.7 样式错乱

确认 _config.yml 的 url 与访问地址一致。

九、配置速查表

配置项 示例
GitHub 用户名 zlx2022
仓库名 zlx2022.github.io
url https://zlx2022.github.io
图片路径 /images/xxx.jpg
部署分支 gh-pages

结语

踩过的坑：装 Pug 渲染器、图片路径写对、推送用 Token、hexo s 用完 Ctrl+C。
